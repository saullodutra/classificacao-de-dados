# Classificacao-de-dados
Repositório para organização e apresentações de trabalhos

# Comandos essenciais de git
| Comando      | O que faz                  |
| ------------ | -------------------------- |
| `git init`   | Cria um repositório        |
| `git clone`  | Baixa um repositório       |
| `git status` | Mostra o estado do projeto |
| `git add`    | Prepara alterações         |
| `git commit` | Salva uma versão           |
| `git push`   | Envia para o GitHub        |
| `git pull`   | Baixa atualizações         |
| `git branch` | Trabalha com branches      |
| `git switch` | Troca de branch            |
| `git merge`  | Junta branches             |
